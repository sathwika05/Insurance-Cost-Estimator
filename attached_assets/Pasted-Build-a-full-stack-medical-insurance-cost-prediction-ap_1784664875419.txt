Backend requirements:

1. Create a FastAPI application.

2. Enable CORS for the Next.js frontend.

3. Create these endpoints:

GET /health

POST /api/predict

4. The POST /api/predict endpoint should accept JSON in this format:

{
  "age": 35,
  "sex": "female",
  "bmi": 28.5,
  "children": 2,
  "smoker": "no",
  "region": "northeast"
}

5. Validate inputs using Pydantic:

- age: integer between 18 and 100
- sex: male or female
- bmi: float between 10 and 70
- children: integer between 0 and 10
- smoker: yes or no
- region: northeast, northwest, southeast, or southwest

6. Convert the input to a pandas DataFrame with the exact column order:

age
sex
bmi
children
smoker
region

7. Run:

prediction = model.predict(input_df)[0]

8. Return:

{
  "estimated_annual_cost": 12345.67,
  "currency": "USD"
}

9. Return clean JSON errors and do not expose Python stack traces.

10. Load the model only once at startup.

11. Check that insurance_model.joblib exists and show a clear startup error if missing.

12. Backend requirements.txt must include:

fastapi
uvicorn
pandas
numpy
joblib
scikit-learn
xgboost
pydantic

Frontend API configuration:

- Create a NEXT_PUBLIC_API_URL environment variable.
- Use it for all requests to the FastAPI backend.
- Do not hard-code localhost in the React component.
- Create a reusable API function in frontend/lib/api.ts.

Use:

POST `${NEXT_PUBLIC_API_URL}/api/predict`

Replit requirements:

- Configure the FastAPI backend to run on host 0.0.0.0.
- Use the Replit PORT environment variable when available.
- Configure the Next.js frontend to run on a separate port.
- Ensure both frontend and backend can run in Replit.
- Add clear run instructions in README.md.
